# Источники

## История и факты
1. Go Blog — *Toward Go 2* — https://go.dev/blog/toward-go2  
   Что проверено: начало разработки, состав команды, открытый релиз 2009, Go 1 в 2012.

2. Go Blog — *Go version 1 is released* — https://go.dev/blog/go1  
   Что проверено: дата Go 1, поддерживаемые платформы, идея стабильности Go 1.x.

3. Go Talk — *Go: a simple programming environment* — https://go.dev/talks/2012/simple.slide  
   Что проверено: цели языка, конкурентность, эффективность, масштабируемость, образ Go в 2012 году.

4. Go Talk — *The Go Programming Language* — https://go.dev/talks/2010/go_talk-20100112.html  
   Что проверено: ранняя мотивация, история разработки, характеристики языка.

5. Go Blog — *Go: one year ago today* — https://go.dev/blog/1year  
   Что проверено: открытый релиз 2009 года, раннее сообщество, назначение языка.

6. Go Blog — *Go 1.1 is released* — https://go.dev/blog/go1.1  
   Что проверено: изменения Go 1.1 и улучшения производительности.

7. Go Release History — https://go.dev/doc/devel/release  
   Что проверено: даты Go 1.0, Go 1.0.x и Go 1.1.

8. Go FAQ — https://go.dev/doc/faq  
   Что проверено: позднейшее использование Go в Google, Docker и Kubernetes; использовано только как контекст, не перенесённый в эпоху 2009–2013.
