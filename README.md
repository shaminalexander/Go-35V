## Коротко о проекте
Рекламная страница вымышленных курсов по Go, стилизованная под раннюю эпоху языка: от открытого релиза 2009 года до первых стабильных лет после Go 1.0 в 2012 году. Концепция строится вокруг обещания сделать сетевые и серверные программы проще, сохранив компиляцию, статическую типизацию и встроенную поддержку конкурентного выполнения.

Страница намеренно использует плотную «инженерную» композицию, терминальные мотивы и эстетику раннего веба, а не современный SaaS-дизайн.
