# Лабораторный экран

## Назначение
Показать ощущение работы с Go через короткий фрагмент терминала.

## Содержание
Псевдосценарий: `go run hello.go`, затем строка результата и пример запуска нескольких goroutine.

## Связь с объектом
Командная строка, компиляция и конкурентное выполнение.

## Связь с эпохой
Терминал и локальная разработка.

## Визуальные ориентиры
Тёмная прямоугольная панель с моноширинным текстом.

## Материалы
assets/images/terminal.svg

## Ограничения
Код должен быть коротким; не превращать блок в современную IDE-витрину.
