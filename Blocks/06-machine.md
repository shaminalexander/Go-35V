# Компьютер ученика

## Назначение
Привязать обучение к материальной среде времени.

## Содержание
Карточка с условной машиной: ноутбук/ПК, терминал, интернет, Linux или Windows; рядом — серверная пиктограмма.

## Связь с объектом
Go 1 распространялся для нескольких ОС, включая Linux, Mac OS X и Windows.

## Связь с эпохой
Обычная настольная разработка и сетевое подключение начала 2010-х.

## Визуальные ориентиры
Техническая спецификация, тонкие рамки, небольшие пиктограммы.
